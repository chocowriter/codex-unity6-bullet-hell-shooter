# Unity 6 탄막슈팅게임 with Codex

Unity 6와 Codex를 활용해 제작한 2D 탄막 슈팅 게임 프로젝트입니다. 플레이어 이동, 총알 발사, 오브젝트 풀링, 적 스폰, 웨이브 시스템, 보스 상태 머신, 페이즈별 탄막 패턴, 점수, 파워업, HUD, 사운드, Windows 빌드까지 하나의 플레이 가능한 흐름으로 구현했습니다.

이 프로젝트의 목적은 Codex를 단순 코드 생성 도구로 사용하는 것이 아니라, 게임 개발 과정에서 기능 분해, 코드 초안 작성, 오류 분석, 리팩토링 제안, 최적화 검토를 함께 수행하는 개발 파트너로 활용하는 방법을 실험하는 것입니다.

## 프로젝트 개요

```text
개발 책: [Unity 6 탄막슈팅게임 with Codex](https://wikidocs.net/edit/book/20051)
장르: 2D 탄막 슈팅 게임
엔진: Unity 6000.6.0f1
언어: C#
플랫폼: Windows 11
개발 방식: Unity + Codex 협업 개발
```

플레이어는 화면 안에서 적 총알을 피하며 적을 처치하고, 마지막에는 여러 페이즈를 가진 보스와 전투합니다. 보스는 원형 탄막, 회전 나선 탄막, 조준 탄막, 페이즈 전환 탄막을 사용합니다.

## 주요 기능

### 플레이어 시스템

* 키보드 입력 기반 2D 이동
* 화면 밖 이동 제한
* 일반 공격
* 파워업 단계에 따른 공격 강화
* 피격 시 생명 감소
* 피격 후 무적 시간

* 총알 생존 시간 관리
* 화면 밖 총알 자동 반환
* 충돌 시 풀 반환

### 적과 웨이브

* 일반 적 체력과 사망 처리
* 적 이동 패턴
* 적 공격 시스템
* `WaveData` 기반 웨이브 구성
* 적 등장 시간과 위치 데이터화
* 적 처치 시 점수 추가
* 아이템 드랍 구조

### 보스전

* 보스 등장 흐름
* 보스 상태 머신
* 체력 비율 기반 페이즈 전환
* 페이즈별 탄막 패턴 실행
* 보스 사망 연출
* 스테이지 클리어 전환

구현된 보스 패턴은 다음과 같습니다.

```text

```

### UI와 사운드

## 실행 방법

### Unity Editor에서 실행

1. Unity 6로 프로젝트를 엽니다.
2. `Assets/Scenes/GameScene.unity`를 엽니다.
3. Play 버튼을 눌러 실행합니다.

### Windows 빌드 실행

1. Releases에서 Windows 빌드 zip 파일을 내려받습니다.
2. 압축을 해제합니다.
3. `.exe` 파일을 실행합니다.

> Windows 빌드는 `.exe` 파일과 `_Data` 폴더가 함께 있어야 정상 실행됩니다.

## Codex 활용 방식

이 프로젝트에서는 Codex를 다음 작업에 활용했습니다.

```text
- 기능 구현 초안 작성
- 플레이어 이동과 공격 코드 초안 작성
- 총알 풀링 구조 제안
- 보스 패턴 코드 작성 보조
- NullReferenceException 원인 분석
- OnTriggerEnter2D 미호출 문제 점검
- 긴 코드 리팩토링 제안
- Profiler 결과 기반 최적화 후보 정리
- README와 개발 문서 초안 작성
```

Codex가 작성한 코드는 그대로 사용하지 않고, 다음 기준으로 직접 검토했습니다.

```text
- 기존 프로젝트 구조와 맞는가
- GameManager에 책임이 과도하게 몰리지 않는가
- ScriptableObject에 런타임 상태를 저장하지 않는가
- 오브젝트 풀링 초기화가 안전한가
- 이벤트 구독과 해제가 올바른가
- 코루틴 중복 실행 가능성이 없는가
- Unity Inspector 연결이 필요한 필드가 명확한가
- Play 모드에서 기대 동작이 실제로 수행되는가
```

최종 구조 결정, 게임 밸런스 조정, 탄막 난이도 판단, UI 배치, 사운드 타이밍, 빌드 검증은 개발자가 직접 수행했습니다.

## 회고

이 프로젝트는 Unity 6에서 탄막 슈팅 게임을 완성하는 과정뿐 아니라, Codex를 게임 개발 workflow에 어떻게 통합할 수 있는지 확인하기 위한 실험이었습니다. Codex는 코드 초안 작성과 오류 분석에는 큰 도움이 되었지만, 보스 패턴의 공정성, 탄막 가독성, 플레이 감각, 최종 구조 판단은 개발자가 직접 결정해야 했습니다.

AI 시대의 게임 개발에서 중요한 것은 AI에게 모든 것을 맡기는 것이 아니라, AI가 빠르게 만든 결과를 읽고 검토하고 프로젝트 구조에 맞게 통합하는 능력입니다. 이 프로젝트는 그 과정을 하나의 작은 게임으로 정리한 결과물입니다.
